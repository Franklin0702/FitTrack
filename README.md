# Fit Track App
This app is similar to Yazio but less complex and without ads. 

On this app you can have a profile with a weight, daily calories, daily nutrients (Protein, Carbs, Fiber, Fat), amount of water and exercises routine that you want to target and daily you can track these goals.

It can show statistic about your progress, you can schedule current values updates so the app will remind you to enter your current weight, and other measures if needed so you can see your project. 

The best idea is that it treats nuetrients and calories as a budget so you can add "transactions" that will reduce the avaialble budget on calories and also track nutrients. 

It's free and you can handle unlimited profiles without an account, every profile has a name for different version of you or people sharing the app. 

Also it works completely locally nobody knows of your data it use a local db like sqlite to manage everything and it has option to export all your data to other devices or external formats for you to handle it. 

This apps is built with React Native so it supports Android and Iphone.
